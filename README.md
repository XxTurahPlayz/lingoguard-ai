# 🌍 LingoGuard AI

**AI-powered language identification with uncertainty detection.**

LingoGuard AI identifies four languages:
- 🇮🇩 Indonesian
- 🇬🇧 English
- 🇫🇷 French
- 🇪🇸 Spanish

## 🚀 Live Demo

[**Try LingoGuard AI**][(https://f6cf044eec5c8c0886.gradio.live/)]

## 📌 How It Works

LingoGuard uses character-level TF-IDF features and Logistic Regression to identify the language of a text.

It also includes an uncertainty warning when the model's top score is below 0.60, asking users to provide more text when a prediction is uncertain.

## 📊 Test Results

Evaluated on a held-out test set of 1,200 Tatoeba sentences.

| Model | Accuracy | Macro F1 |
|---|---:|---:|
| Majority baseline | 25.00% | 0.1000 |
| langdetect | 92.17% | 0.9538 |
| **LingoGuard AI** | **99.33%** | **0.9933** |

LingoGuard correctly classified 1,192 out of 1,200 test sentences.

## 🛠️ Technologies

- Python
- scikit-learn
- TF-IDF
- Logistic Regression
- pandas
- Gradio
- Google Colab

## 📁 Project Files

- `LingoGuard_AI_Hackathon_2026.ipynb` — Complete project notebook and model development.
- `lingoguard_submission_assets.zip` — Trained model, error analysis, and confusion matrix.
- `PROJECT_REPORT.md` — Project methodology, evaluation, limitations, and future improvements.

## 🎯 Project Status

Built for the **Veritas AI International High School Hackathon 2026**, under the AI + Languages track.

## ⚠️ Limitations

- Currently supports four languages.
- Short, ambiguous, and unfamiliar text may be misclassified.
- The model has not been established as reliable for code-mixed text.
- Test results do not guarantee perfect performance on real-world text.
